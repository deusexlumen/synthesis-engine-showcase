Why this is not another astrology app

Most projects ship one system and claim “precise” without a number. This one is built the other way around.

Three systems, one synthesis

Not isolated readings. Cross-correlation into a single coherent profile that an LLM can reason across.

Measured error table

Automated tests assert accuracy against a Swiss Ephemeris fixture on every CI run — not a one-time claim.

License-isolated providers

CI fails the build if AGPL ephemeris code reaches the standard image. Professional tier is opt-in.

Server recomputes everything

Any endpoint that persists a chart recomputes it server-side. Client-submitted numbers are never trusted.

Honest data-flow

Earlier “data never leaves your device” claim was retracted after the web pivot. Transparency over marketing.

Tokens never in storage

Automated tests assert access tokens and API keys are never written to browser storage.
